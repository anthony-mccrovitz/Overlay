## Vision

### 10x Check
A sports betting decision engine that combines ensemble ML models, Monte Carlo tournament simulation, game-theory-based pool optimization, real-time odds comparison, and Kelly criterion bankroll management. Not just "predict brackets" — a complete system that quantifies edge, sizes bets, and optimizes for your specific pool.

### Platonic Ideal
Ensemble of 5+ model types with matchup-specific features, tournament-specific adjustments, pool-size-aware bracket optimization, real-time odds arbitrage detection, and a user experience where you input your pool size + bankroll and get THE optimal bracket with bet sizing and plain-English explanations for every pick. Backtested against 15 years of data with confidence intervals on every claim.

## Data Sources
- **Barttorvik** (free): Adjusted efficiency, tempo, Four Factors, experience metrics
- **Kaggle** (free): Clean tournament results, seedings, game scores (1985-present)
- **the-odds-api.com** (free tier): Real-time sportsbook odds

## Key Decisions
- Template-based narratives (not LLM-powered) — reflects actual model reasoning
- CLI + Jupyter notebook output format
- Barttorvik + Kaggle data sources (free, reproducible)
- Numpy-vectorized Monte Carlo for speed
